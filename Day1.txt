DBMS: DataBase Management System:
it is a software
The main purpose of dbms is used to store data permently and manage data.
Advantages of DBMS:
reduce data redundancy
to provide more security
to improve data inconsistency
possible to recover and backup the data
to maintain readability
Types of DBMS:
NoSQL dbms: The data is stored into unstructured format.  Ex: MongoDB, postgre sql
RDBMS: it stands for Relational database management system, in RDBMS the data is stored in rows and colums(table format),
         the data is stored in the structured format.
         EX: MySQL, oracle...etc
