window functions:
-------------------
it is mainly used to find the row numbers and ranks 
it is popular function in MySQL
 types
row_number()
rank()
dense_rank()
ntile()

aggregate function:
---------------------
avg()
max()
min()
count()
sum()

offset function:
-------------------
first_value()
lag()
lead()

syntax of window function:
----------------------------
select columnlist, functionname over() as aliasname from tablename;

in window represented by over():
-------------------------------
partition by: it is used to divided the data into group based on cloumn
order by: to sort the data into a order based on column.
